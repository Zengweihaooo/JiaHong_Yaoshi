# JiaHong Yaoshi（嘉虹药师端）

嘉虹医疗产品体系中的**药师工作台**前端项目。

---

## 项目简介

JiaHong Yaoshi 面向药房药师，用于承接医生开具处方后的审核、调配与流转等环节，与医生端、患者端及管理后台共同构成互联网医药服务闭环。

本项目负责药师侧的业务界面与交互实现，视觉与基础组件统一复用 [JiaHong UI](https://github.com/Zengweihaooo/JiaHong_UI) 设计系统。

---

## 核心职责

药师端主要承载以下能力（规划方向，随迭代细化）：

- **处方审核**：查看医生提交的处方，核对用药合理性后通过或驳回
- **处方流转**：处理处方状态变更（如审核通过、作废、留痕追溯）
- **咨询协同**：配合图文/复诊等场景下的用药说明与患者沟通
- **工作台**：待办列表、消息提醒、门店/药房上下文切换
- **风险与合规**：结合用药风险检测结果辅助审核决策

---

## 不负责的内容

与 [JiaHong UI](https://github.com/Zengweihaooo/JiaHong_UI) 及兄弟项目保持一致的分工边界：

- 通用 UI 组件与设计规范（由 JiaHong UI 提供）
- 医生开方、问诊主流程（由医生端 JiaHong Yisheng 负责）
- 患者下单、支付、小程序等（由患者端负责）
- 平台级运营与权限配置（由管理后台负责）

## 技术栈（规划）

与嘉虹现有前端项目对齐：

- Vue 3
- Vite
- Vue Router
- Pinia（状态管理）
- Element Plus
- `@jiahong/ui`（嘉虹统一组件库）
